# Scientific Calculator: Kalkulator Ilmiah dalam Satu File

![Scientific Calculator](img/proyek/scicalc.jpg)

Kalkulator ilmiah modern dengan tampilan **dark glassmorphism**: panel transparan seperti kaca buram di atas latar gelap.

Seluruhnya dibuat dengan **HTML, CSS, dan JavaScript murni** dalam **satu file**, tanpa framework dan tanpa instalasi apa pun. Cukup buka filenya di browser dan kalkulator langsung bisa dipakai.

Teknologi: HTML, CSS, JavaScript.

Kode lengkap: [github.com/des1susanti/scientific-calculator](https://github.com/des1susanti/scientific-calculator)
