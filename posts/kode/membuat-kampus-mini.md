# Membuat Kampus Mini 3D

Portofolio ini dibuat dengan **Three.js** dan JavaScript biasa, tanpa server. Semua isinya ada di folder proyek, jadi bisa dibuka lewat **GitHub Pages**.

## Bagian-bagiannya

- `js/world.js` — pulau, jalan, danau, pohon, dan gedung-gedung
- `js/robot.js` — robot yang bisa berjalan dan berganti warna
- `js/physics.js` — fisika sederhana: kardus, huruf, dan bola bisa didorong
- `js/content.js` — semua teks portofolio (Indonesia & Inggris)
- `posts/` — tulisan blog dalam format Markdown

## Menulis tulisan baru

1. Buat file `.md` di folder `posts/kode`, `posts/kuliner`, atau `posts/jalan-jalan`.
2. Daftarkan di `posts/index.json`.
3. Simpan, lalu unggah ke GitHub.

```js
// contoh kode di dalam tulisan
console.log("Halo dari Kampus Mini!");
```
